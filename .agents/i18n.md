# I18n

- Add server and JavaScript keys only under `source/i18n/SC`, `TC`, and `EN`.
- Site names, navigation names, online-role titles, and forum names are JSON objects keyed by `SC`, `TC`, and `EN`; use `i18n::localizeValue()` rather than branching on the locale.
- Store manual `common_secquestion.question` values as JSON maps keyed by those locale names.
- Rebuild language/template caches after changing rendered keys.
